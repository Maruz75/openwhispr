# Bisik implementation contract

Native SwiftUI app, iPhone/iPad, deployment iOS 17, Swift 5 language mode. All UI Indonesian. Root owns Xcode project, app entry, plist, entitlements, resources and docs. Services agent owns Core/, Services/, BisikTests/. UI agent owns Views/. Backend agent owns backend/.

## Observable view model (services agent implements)

`@MainActor final class AppModel: ObservableObject` with `@Published var text: String`, `phase: RecordingPhase` (`idle`, `preparing`, `recording`, `processing`), `levels: [CGFloat]` (32 real metering samples), `elapsedSeconds: Double`, `history: [TranscriptRecord]`, `dictionary: [DictionaryEntry]`, `settings: AppSettings`, `quota: UsageQuota?`, `errorMessage: String?`, `copied: Bool`, `showPaywall: Bool`, `needsConsent: Bool`, `needsSignIn: Bool`, `isSignedIn: Bool`, `products: [StoreKit.Product]`, `isPurchasing: Bool`, `isConfigured: Bool`, `learnedCount: Int`, `hasPendingRecording: Bool`.

Methods: `func bootstrap() async`, `func beginHold() async`, `func endHold() async`, `func cancelRecording()`, `func retryTranscription() async`, `func copyText()`, `func commitEdits()`, `func newDraft()`, `func openHistory(_ record: TranscriptRecord)`, `func deleteHistory(_ id: UUID)`, `func clearHistory()`, `func addDictionary(source: String, replacement: String)`, `func deleteDictionary(_ id: UUID)`, `func saveSettings()`, `func acceptConsent()`, `func revokeConsent()`, `func signIn(identityToken: String, nonce: String) async`, `func signOut()`, `func deleteAccount() async`, `func purchase(_ product: Product) async`, `func restorePurchases() async`, `func refreshQuota() async`.

`TranscriptRecord: Identifiable, Codable` id UUID, text String, originalText String, createdAt Date, durationSeconds Double. `DictionaryEntry: Identifiable, Codable` id UUID, source String, replacement String, learned Bool, createdAt Date. `AppSettings: Codable` autoCopy Bool=true, learnCorrections Bool=true, haptics Bool=true, saveHistory Bool=true, language String="id-ID", consentGranted Bool=false. `UsageQuota: Codable` usedSeconds Int, limitSeconds Int, resetAt Date, plan String (free/pro); computed remainingSeconds Int, progress Double. `AppConfiguration` static fields apiBaseURL: URL?, privacyURL: URL?, termsURL: URL?, aiProviderDisclosure: String, productIDs: [String], freeMinutes: Int=15, proMinutes: Int=300.

Local data persistence JSON + file protection. Clipboard write only. On-device Apple Speech live preview if supported; final transcript always developer backend. No user AI/model/endpoint choices. Manual edits commit on keyboard Done/focus loss, learn only conservative aligned lexical substitutions; use dictionary as context/replacements in next transcription. History edits update existing record; avoid overwriting a draft before permissions/consent/auth succeeds. Hold release during async preparation must not start recording later. On interruption/background cancel safely without upload. Keep failed recording temporarily for explicit retry, delete after success/cancel. Network quota failure cannot fall back to client billing. Quota limit auto-stops hold. VoiceOver offers tap start/stop. Purchases must sync signed JWS with server before finish; retain/retry unfinished verified transactions.

## Backend API (FastAPI/Python)

HTTPS. Paths below relative to base URL (base URL has no /v1 suffix). Bearer opaque session in Keychain. All response JSON camelCase.

POST `/v1/auth/apple` JSON `{identityToken, nonce, authorizationCode?}` (raw nonce; server matches SHA256(nonce) to claim). Validate Apple JWT, issuer/audience, expiry/nonce. Authorization code required for new account; encrypted refresh token enables Apple credential revocation. Returns `{accessToken, accountToken, quota}` (UUID accountToken stable user, for StoreKit appAccountToken). DELETE `/v1/account`: revokes Apple credential, removes account data and sessions. POST `/v1/auth/logout`: revoke current session. GET `/v1/quota`: UsageQuota.

POST `/v1/transcriptions` multipart: `file` (m4a or wav), `requestID` UUID idempotency, `dictionary` JSON array `[{source,replacement}]`, `language` locale e.g. id-ID. Response `{text, quota}`. Server measures duration via ffprobe, atomically reserves quota, no client-trusted duration, compensates failed upstream, returns prior success on same requestID, handles concurrency. Never return invented transcript on provider failure. Developer-only env selects STT and cleanup model/provider keys. Learned dictionary replacements applied conservatively. Keep no raw audio/transcript server-side after idempotency cache TTL. Free 900 sec/pro 18000 sec per UTC calendar month (including yearly plan). Server may override via env. Error JSON `{code,message}` (quota_exceeded HTTP402, unauthorized HTTP401; no provider secret/raw upstream in errors).

POST `/v1/subscriptions/verify` JSON `{signedTransaction}`. Verify with Apple official app-store-server-library signed-data verifier (trusted roots, bundleID, environment, appAppleId prod), product allowlist, appAccountToken matching. Refresh status with App Store Server API (server keys) before granting; do not trust old/revoked JWS. Return `{quota}`. App catches unavailable deployment config; purchase UI displays real StoreKit price/duration (no hardcoded sell price), restore/manage/EULA/privacy. Developer setup remains documented.

Root adds `.github/workflows/native-ios.yml`: macOS simulator compile/test; backend tests on Linux/Windows local. No credentials in repo. Production release needs signing identifiers, Apple product setup, HTTPS API, root certificates, server keys, legal URLs.
